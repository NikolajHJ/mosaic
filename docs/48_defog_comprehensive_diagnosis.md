## What the current integration actually proves

The source079 native gate made eight prescribed DeFoG attempts and accepted
eight eligible native targets. Two targets were selected at two refreshes.
It completed six accepted latent updates with nonzero guidance and seven
passing target-only finite-difference checks. This proves that the corrected
interface can generate repair references and send decoder-loss gradients
to molecular `z` under the tested short protocol.

The encoder, decoder, Boltz affinity/confidence models and DeFoG checkpoint
remain frozen. Only molecular `z` is optimized. One shared relaxed graph
is scored by Boltz. Outside autograd, a prescribed hard draw is mapped into
the adapter's neutral, fixed-count subset of a public model with unmodeled
formal charges; unsupported charges
and labels are rejected, not silently neutralized. A repaired graph may
become a different, explicit detached guidance reference. It never replaces
the shared Boltz graph. No gradient is claimed through hard drawing, DeFoG
transitions, target eligibility or target selection.

The fixed target and weight must remain constant for the analytic gradient,
FD probes and line-search calls at one state. The next target is selected
only at a declared refresh boundary. These are gradients of the frozen-target
decoder loss, not DeFoG likelihood gradients or exact derivatives of the
stochastic repair procedure. Raw graph validity, native binding, synthesis
and usefulness require separate evaluation.

The public checkpoint has no formal-charge input/output channel; that is not
evidence that its training molecules were all neutral. Public native molecule
postprocessing can infer +1 charges on N/O/S and select a largest connected
fragment. Our strict adapter instead preserves declared atom/charge/count/
slot identity and requires a connected neutral target; it does not apply
hidden charge inference or fragment removal. Thus the sanitization and
disconnected rejections are partly consequences of an explicit stricter
contract. The [DBMol paper](DBMol.pdf) uses a distinct charge-aware ZINC DeFoG
prior trained for 300 epochs; the public GuacaMol checkpoint is not a faithful
substitute for that model's charge representation. Primary sources are
[DBMol Appendix C](https://arxiv.org/html/2607.19237v1#A3) and the pinned
[native molecule postprocessor](https://raw.githubusercontent.com/manuelmlmadeira/DeFoG/365bda9affadd5c2307014a0532ddaa244399441/src/analysis/rdkit_functions.py).

The audited native timestep mapping also differs from a naive 200-step
suffix: pinned `polydec` uses f(u) = 2u - u², so requested distorted model
time 0.8 starts at grid index 553, effective time 0.8001910448074341, and takes
447 transitions. Saved transition receipts agree. Candidate insertion at
that time is still a declared repair heuristic, not proven native conditional
sampling or a nearest-valid projection. The pinned
[time-distorter source](https://raw.githubusercontent.com/manuelmlmadeira/DeFoG/365bda9affadd5c2307014a0532ddaa244399441/src/flow_matching/time_distorter.py)
defines this schedule.

The scoped checkpoint-availability audit examined the authors' public
homepage/repositories, DBMol repository search, exact public Hugging Face
search and the [public DeFoG release](https://drive.switch.ch/index.php/s/MG7y2EZoithAywE).
It did not identify the actual charge-aware DBMol checkpoint; that is a
bounded search result, not proof the model is globally unavailable. The
public `zinc.ckpt` (253,424,695 bytes) also has no charge channel and uses
nine elements/four bond classes with kekulized bonds, per the pinned
[ZINC dataset source](https://raw.githubusercontent.com/manuelmlmadeira/DeFoG/365bda9affadd5c2307014a0532ddaa244399441/src/datasets/zinc_dataset.py).
It must not be assumed to be DBMol's charge-aware model or a drop-in schema
replacement. A separately declared charge-omitting model view does not need
that unavailable-in-the-scoped-search checkpoint: public GuacaMol consumes
atom symbols/bonds without a charge channel. This changes the feature-loss
contract, not its neural capability or faithful DBMol replication. The
unsupported selenium rejection was specifically prior 6,
first refresh/attempt 0, native position 9.

## Runtime root cause and remaining budget checks

Source079 declares a 23-hour A100 allocation, a 7,200-second six-update gate,
6,000-second 100-update children, 900-second per-case fresh-pose budget and
a 79,200-second controller. Long repair refreshes occur every ten accepted
updates. Although the periodic audit interval is 50, the implementation runs
the full Boltz component and total FD suite at each refresh: states
0/10/.../90/100, eleven full gates per complete trajectory.

For timeout seeds 1/2/4, Boltz FD consumed 3,439.975/3,679.071/3,906.834 seconds,
versus DeFoG 803.238/707.528/653.327 seconds, actual updates
370.104/378.573/402.310 seconds and line searches
793.038/632.327/435.672 seconds. The expensive scorer audit, not only native
repair, consumed the budget. Nested accounting categories are not independent
wall times and must not be summed twice. Execution receipts establish cap
termination even when a killed child's run record remains stale `running`.

A future runtime change needs explicit per-category oracle counts, measured
worst-case audit/repair/line-search costs, checkpoint/termination receipts
and a case-boundary controller reserve. Any change in validation cadence
must say which checks remain mandatory at refreshes versus periodic states;
it cannot silently weaken a failed numerical gate or turn a timeout into
completion. No such production change is recorded in this report yet.

exclude gross loss assembly, observed mode mismatch and stochastic drift for
these cases. They do not establish that every random-direction slope is
correct: the failed FD patterns reproduced and all original gates remain
failed. The policy still requires 5% relative/1e-6 absolute tolerance and
two neighboring informative passing scales in each required direction.

Contact winners were stable on the relevant small probes, so winner changes
alone do not explain those rows. FP32 cancellation/representable-input effects,
smooth curvature and a native derivative mismatch still need discriminating
measurements. A numerical explanation needs exact endpoint input/logit/score
precision and directional signal relative to repeat/rounding floors, plus
an independent higher-precision or faithful isolated-operation check where
available. Merely loosening tolerance, clipping or selecting a favorable
epsilon is not a root-cause result.

The implemented and **HPC-executed diagnostic**
[attention diagnostic](../src/latentmol/boltz/attention_causal_diagnostic.py)
adds three prespecified controls at the same authenticated source079 states

QK, both bias additions and softmax in FP64, then casts probabilities back

forward arithmetic as well as derivatives. Frozen weights do not make these
variants the same scorer mathematics.

An observer records actual all-masked-row exposure and objective cotangents.
The earlier source060 context had no wholly masked triangle rows; its toy
mask failure was therefore not a demonstrated cause of that molecule's
mismatch. Source081 measures exposure in these actual failed states rather
than assuming the toy mechanism applies. A null attention control is useful
negative evidence, while the decoder readout remains a separate test.
A bounded captured row can be tested with its fixed native cotangent;
different reduced shapes may select another kernel, so captured-output parity
is checked and isolated-row evidence remains separate from end-to-end
