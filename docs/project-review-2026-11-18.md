# Where to take DBMol and Mosaic

**Session close, 20 November. Use the direct relaxed graph as the primary method.** A 15,853-parameter model learned ordinary atom identities, connectivity and bond orders with no aromatic label or ring bonus. On 48 newly reserved acyclic PubChem molecules with ten atoms protected, 14 first draws contained an aromatic ring. Selecting one of 12 draws by a generic chemistry score yielded 36/48 aromatic, 32/48 with a six-carbon aromatic ring and 10/23 newly amide-positive among eligible sources. Those are graph-level results. On an independent 144-source selection panel the same scoring principle returned 63 whole-MMFF aromatic passes versus 50 with first-valid selection. More ordinary training data improved single-draw yields in two training seeds. Keep first draws, best-of-budget selections, and physical qualification visible as separate columns. **20 November, direct generation.** A 15,853-parameter continuous graph model now creates rings from all-single untyped trees while jointly choosing atom identities, new edges and ordinary orders. Among the first draws, six aromatic and one multiple-aromatic endpoint passed whole-molecule MMFF. ## What the project set out to learn

The August Latent-DBMol proposal asks whether a learned molecular space yields more valid, diverse molecules while retaining the target signal after decoding. Its first milestone is fixed size, a frozen Boltz-2 scorer, a direct-graph baseline, equal model calls and held-out evaluation. It explicitly allows a scientifically valuable outcome in which the direct graph wins. Hidden-state alignment, variable size and multiple property objectives come later. A September design explored a small KIBA predictor as a sandbox. The 26 September revision took the AE → matched VAE → frozen Boltz-2 route. The 55,671-byte August text is preserved from the editor-history entry for the exact project path, matching the offline OneDrive file's size and save time. [August proposal](history/latent-dbmol-proposal-20260813.md) · [September protocol](../outputs/release-staging/source-052-equal-repair-quality/docs/project_desc.pdf) · [Dated change of scope](02_implementation_plan.md)

Mosaic v12 asks the complementary question of how much chemistry a direct, differentiable graph optimizer needs. It specifies native atom and bond gradients, an unconstrained baseline, explicit feasibility and finally a frozen moving teacher. Geometry-free ligand PAE requires frames the wrapper cannot supply. The specified fallback uses the whole BRD4 domain. Many later studies use a JQ1-defined pocket and a different contact reduction. Those studies answer a target-conditioned design question. Neither a pocket contact gain nor a fixed-pose Boltz loss is measured binding. The published DBMol work also distinguishes its optimization metric from held-out evaluation. ## What I would ask the agents to do

1. **Evaluation agent — test whether the score can select a useful molecule.** Start with existing archives. Freeze a small scaffold-diverse shortlist, include the corresponding founders, matched unselected molecules and a known ligand or documented actives/inactives for the same pocket. Blind their origins. Rebuild the hard inputs, record changes in identity, stereo/charge support and failed conformers, and score each with the same independent pose or docking procedure. Keep a second geometry seed set out of selection. Compare ranking against the controls and count how many search improvements survive. This is urgent because the earlier T4 lysozyme geometry-off test ranked hexane ahead of its known benzene ligand. The evaluation branch has a real single-ligand Vina exercise and fixture-tested optional native adapters. Its published comparison tables supply context only. [Known-ligand control](../../mosaic/docs/known_ligand_1000.md) · [Evaluator validation](../../mosaic/experiments/validation/molecule-evaluation.md)
2. **Search agents — run one comparison that isolates the representation.** Share fixed 25-atom founders of verified identical hard identity, target/pocket, element and charge support, scoring settings, archive rules and parent feedback. Compare frozen epoch-45 latent gradients with Mosaic direct relaxed-graph gradients. Include a cheap discrete graph-edit or random proposal control to price the gradients. Start with three unseen seed panels and a small predeclared common scorer-call budget. The existing BRD4 Protenix setup is a practical first test if it scores both representations identically. To address the August milestone, repeat the matched fixed-25 comparison with Boltz on that pocket. To test target transfer, change only the pocket. Keep the 31-slot fixed-pose BRD4 Boltz result in its own row. [Direct/latent pilot][direct] · [Fixed-pose BRD4 run][boltz] · [Original benchmark design](history/latent-dbmol-proposal-20260813.md)
3. **Chemistry agent — finish the comparisons already in flight.** The three fragmented-start DeFoG versus structural-repair pairs and the four-seed, two-scorer defect/retention/rescue study are already commissioned. The 18 November read-only queue check found these jobs pending. Read them together with the passive-archive baseline. If the selected DeFoG recipe wins, spend the next small allocation on starts withheld from tuning. A fixed-initial-teacher arm is a useful mechanism control if the claim concerns refreshing the teacher. [DeFoG/repair pair][repairpair] · [Two-scorer study][rescue] · [Stage 3 analysis][defog-report]
4. **Training agent — diagnose the size collapse with a bounded replay.** Use the same epoch-46 parent, real batches, prior vectors, update count and optimizer state. Change one source of size supervision at a time. An atom-preserving bond repair reproduces the occupied slots chosen by the decoder, even when it chooses 50. Compare the current loss with an explicit count-distribution or frozen occupancy reference. Report raw prior validity, count histogram, distinct scaffolds and held-out reconstruction at common checkpoints. Consider larger training only if the modified arm recovers prior quality while preserving reconstruction. [Objective and fixed-panel diagnosis](../experiments/vae/representation-search-review.md) · [Existing corpus campaign](../experiments/vae/large-corpus.md)

**How I would decide.** For each unseen start, report the count of distinct valid, connected, scaffold-diverse molecules that improve over their founder under fresh scoring, and the fraction that retain the gain in the blinded readout. Show best-three quality and final state separately. Compare common prefixes of actual model calls and wall time, including failed attempts, cheap proposals and unused allowances. A result concentrated in one lineage justifies another small panel. A reproducible independent advantage earns a second pocket. A tie favors the cheaper proposer and frees the VAE for founder generation. If the independent metric cannot rank reference controls usefully, fix the evaluation before selecting another design method.
