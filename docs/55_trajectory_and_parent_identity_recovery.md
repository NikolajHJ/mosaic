## The chemistry parent was rejected because JSON was read through YAML

The saved parent configuration is canonical JSON written from the training
dataclass. It contains the JSON number `"weight_decay": 1e-05`. Chemistry setup
used `TrainConfig.from_yaml` to read this `.json` artifact. The installed YAML
resolver accepts its overall syntax but interprets that particular exponent
spelling as the **string** `"1e-05"`. The checkpoint has the correct float
`1e-05`. Exact configuration comparison therefore rejects the phase boundary
before optimizer restoration or chemistry updates.
