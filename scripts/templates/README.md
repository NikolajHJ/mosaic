# Legacy report template paths

These HTML files are byte-identical declarative compatibility copies. Their
canonical owners are listed in the [migration map](../../experiments/MIGRATION.md):
the generic Protenix template is shared under `scripts/reporting/`; milestone
and JQ1 templates live with their reporting/scientific experiments.

Keep these copies synchronized when an authorized template edit is made; the
layout checker verifies equality. Existing published report editions are
independent artifacts and remain untouched. Never infer scientific acceptance
from successful rendering or publication.
