# JQ1 fixed-step comparison: scripts

This folder belongs to [the experiment protocol](../README.md).

- [jq1_fixed_report_contract.py](jq1_fixed_report_contract.py): Exact saved-artifact contract for the three fixed-step JQ1 trajectories.
- [jq1_fixed_report_ops.py](jq1_fixed_report_ops.py): Allocated orchestration for the separate fixed-step saved-only report.
- [publish_jq1_fixed_report.py](publish_jq1_fixed_report.py): Publish independently byte-verified fixed-step JQ1 report assets.
- [render_jq1_fixed_interim.py](render_jq1_fixed_interim.py): Allocated fixed-step progress editions from authenticated saved prefixes only.
- [render_jq1_fixed_report.py](render_jq1_fixed_report.py): Allocated saved-only fixed-step JQ1 report with exact bounded FP32 assets.
