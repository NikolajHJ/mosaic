How to read this geometry

Sphere colors show each slot’s most probable element. Rings mark element mixtures. Line weight shows the input bond probability, and dashed lines have less than 50% support. Lime highlights the measured pair.

Receptor alignment sets the common orientation. Each ligand view is centered for inspection, and the comparison uses a common scale. Distances are measured in Å.
